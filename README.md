# Zombi Ubisoft (1986) PHP

Quand il n'y a plus de place en enfer, les morts reviennent sur terre...

**Play: https://jumphp.net/zombi-ubisoft-1986-php**

Made with [JumPHP](https://github.com/davidnurdin/jumPhp): retro games in PHP, on the desktop and in the browser.
The game is in `games/zombi-ubisoft-1986-php/`.

```bash
bin/jumphp install zombi-ubisoft-1986-php    # dependencies (everything runs in Docker)
bin/jumphp run zombi-ubisoft-1986-php        # play on the desktop
bin/jumphp test zombi-ubisoft-1986-php       # checks + a headless demo
```
