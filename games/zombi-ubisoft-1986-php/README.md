# zombi-ubisoft-1986-php

Jeu JumPHP. Depuis la racine du dépôt :

```bash
bin/jumphp install zombi-ubisoft-1986-php   # dépendances
bin/jumphp run zombi-ubisoft-1986-php       # jouer sur le bureau
bin/jumphp test zombi-ubisoft-1986-php      # vérifications + test automatique sans écran
bin/jumphp build zombi-ubisoft-1986-php     # version navigateur -> dist/web
bin/jumphp serve zombi-ubisoft-1986-php     # http://localhost:8080
```

Commandes : flèches / WASD pour bouger, Espace pour sauter, Échap pour la pause.
